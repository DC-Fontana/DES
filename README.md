# DES (Desktop Executive System)

DES is a voice-first private AI operating system.

## Monorepo layout

- `apps/web` – Next.js control UI.
- `apps/desktop` – Tauri shell and desktop capabilities.
- `services/api` – FastAPI orchestration + agent runtime.
- `packages/ui` – shared design system.
- `packages/types` – shared TypeScript contracts.
- `docs` – architecture, schemas, wireframes, roadmap.

## Getting started

This repository is bootstrapped with architecture-first documentation and phase-based implementation planning.

Read `docs/01-system-architecture.md` through `docs/07-development-roadmap.md` in order.
