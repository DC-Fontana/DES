# 05 — Memory Architecture

## Memory layers

1. **Short-term context**
   - Active session context window.
2. **Long-term personal memory**
   - Preferences, habits, communication style.
3. **Project memory**
   - Goals, constraints, files, milestones.
4. **Knowledge graph memory**
   - Entity relationship map.

## Memory pipeline

- Ingest event/message.
- Classify memory importance.
- Summarize and chunk.
- Embed and index.
- Link entities and update graph.
- Store encrypted references.

## Retrieval strategy

- Hybrid retrieval (semantic + keyword + graph neighborhood).
- Recency and relevance re-ranking.
- Explainable memory citations in responses.
