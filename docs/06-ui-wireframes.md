# 06 — UI Wireframes

## 1) Home
- Left rail: navigation.
- Center: “What should we build today?” briefing card.
- Right: system pulse + recent activities.

## 2) Voice Interface
- Full-screen cinematic orb/waveform.
- Live transcript split (user / DES).
- Interrupt button + push-to-talk hold state.

## 3) Memory Center
- Search bar with semantic toggle.
- Timeline + graph tabs.
- Memory detail panel with source links.

## 4) Projects
- Kanban + timeline mode.
- AI recommendations panel.

## 5) Skills
- Installed skills grid.
- Enable/disable + permission scopes.

## 6) Integrations
- Provider cards with auth status.
- Test connection and scope management.

## 7) Settings
- Voice, privacy, providers, local model preferences.

## 8) System Activity
- Auditable command/event log.
- Filters: agent, capability, risk level.
