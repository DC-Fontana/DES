# 07 — Development Roadmap

## Phase 1 (Foundation)
- Voice assistant loop (PTT + streaming STT/TTS).
- Memory ingestion + retrieval v1.
- Local DB schema and migrations.
- Basic desktop actions with approvals.

## Phase 2 (Perception + Control)
- Vision pipeline (OCR + UI understanding).
- Browser automation adapters.
- Multi-agent orchestration v1.
- Project workspace management.

## Phase 3 (Orchestration)
- Advanced planning/execution engine.
- Knowledge graph expansion.
- Autonomous workflow runner (bounded).

## Phase 4 (Platform)
- Cross-device sync.
- Plugin ecosystem.
- Continuous background execution with policy controls.

## Implementation kickoff

Start with:
1. API skeleton + auth + permissions middleware.
2. Desktop voice capture and streaming transport.
3. Web voice interface and activity feed.
4. Memory write/read endpoints and tests.
